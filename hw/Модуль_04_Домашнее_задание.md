```text
Модуль 04
Тема: Модуль 04 DTO и AutoMapper Репозиторий с использование EF Core
Цель: самостоятельно разработать небольшой ASP.NET Core Web API, применив изученные на занятии EF Core, Repository, DTO, AutoMapper и единый формат ответа. Эти темы соответствуют основным компонентам модуля презентации.
Задание
Разработайте с нуля проект «Каталог книг» (Book Catalog API).
Система должна позволять хранить и управлять информацией о книгах.
Каждая книга должна содержать как минимум:
Id
Title
Author
Year
Price
Description
Самостоятельно определите типы данных, ограничения полей и структуру классов.
В проекте необходимо реализовать:
Подключение базы данных с использованием Entity Framework Core.
Хранение строки подключения в конфигурации приложения.
Создание базы данных подходом Code First.
Использование Repository для работы с данными.
Отдельную DTO-модель для данных, возвращаемых клиенту.
Преобразование Entity ↔ DTO с помощью AutoMapper.
Единый формат ответа API - ReturnResult.
Полный набор CRUD-операций:
GET     - получить все книги
GET     - получить одну книгу
POST    - добавить книгу
PUT     - изменить книгу
DELETE  - удалить книгу
Дополнительно реализовать возможность поиска книг по автору.
Подходы Code First и миграции, необходимые для создания БД из классов приложения, рассматриваются в презентации. Repository должен отделять приложение от непосредственной логики доступа к данным.
Минимальные подсказки
Готового кода нет. При проектировании ориентируйтесь на общую архитектуру:
Client
   ↓
Controller
   ↓
DTO ↔ AutoMapper ↔ Entity
                     ↓
                 Repository
                     ↓
                  EF Core
                     ↓
                 Database
AutoMapper в проекте должен использоваться именно для преобразования объектов, а не ручного копирования каждого свойства.
Результат
Необходимо  запустить проект и продемонстрировать его через Swagger: создание книги → получение → изменение → поиск по автору → удаление.
Также необходимо уметь объяснить назначение каждого элемента собственной архитектуры: Entity, DTO, DbContext, Repository, AutoMapper и ReturnResult.
Важно: проект должен быть создан самостоятельно. Простого копирования проекта, разработанного на практическом занятии, недостаточно - необходимо самостоятельно определить структуру классов и реализовать взаимодействие компонентов.
```

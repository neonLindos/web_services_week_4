# Практическая работа — Модуль 04

**Тема:** EF Core, Repository, DTO и AutoMapper.
**Проект:** TeamPractice (Team).
**Используемые технологии:** .NET 10, ASP.NET Core, SQLite, AutoMapper, Swagger.

Условие: [Markdown-копия](Модуль_04_Практическая_работа.md), [оригинал](../Модуль%2004%20Практическая%20работа.docx).

## Как запустить

В этой папке выполните:

```powershell
dotnet tool restore
dotnet restore
dotnet ef database update
dotnet run --launch-profile http
```

Откройте http://localhost:5191/swagger. Строка подключения — в appsettings.json, SQLite создаётся миграцией Code First. Отдельный сервер БД не нужен.

## Что реализовано

| Метод | Endpoint | Назначение | Успех |
|---|---|---|---|
| GET | `/api/team` | Все записи | 200 |
| GET | `/api/team/{id}` | Одна запись | 200 |
| POST | `/api/team` | Создать | 201 + Location |
| PUT | `/api/team/{id}` | Изменить | 200 |
| DELETE | `/api/team/{id}` | Удалить | 200 |
| GET | `/api/team/city/{city}` | Команды указанного города (точное совпадение с учётом регистра) | 200 |

Отсутствующий id возвращает 404. Ошибки привязки JSON возвращают 400. Ответы используют ReturnResult, включая ошибки; HTTP-код сохраняет смысл результата.

DTO содержит только Id, Name, City. Поле Description есть в Entity, но не передаётся через DTO. При создании оно остаётся пустым; при изменении существующее значение сохраняется. Id для POST назначает БД, для PUT используется id из маршрута.

## Демонстрация

В Swagger выполните POST с телом:

```json
{"id":0,"name":"Astana Team","city":"Astana"}
```

Сохраните возвращённый id. Выполните GET по нему, PUT с изменёнными полями, поиск по новому городу, DELETE и повторный GET (404). Примеры запросов — в [TeamPractice.http](TeamPractice.http); подставьте фактический id вместо 1.

## Контрольные вопросы

1. **Entity и DTO** — Entity описывает таблицу, DTO ограничивает данные, которыми обменивается клиент.
2. **DbContext и DbSet** — контекст управляет запросами и изменениями, DbSet представляет набор сущностей.
3. **Code First** — схема создаётся из модели с помощью миграций.
4. **Repository** — скрывает EF Core за интерфейсом; контроллер не обращается к контексту напрямую.
5. **AutoMapper** — выполняет преобразование Entity ↔ DTO через CreateMap и ReverseMap.
6. **ReturnResult** — задаёт общий формат тела ответа, сохраняя правильные HTTP-коды.

Автоматическая проверка из корня репозитория: `dotnet run --project checks`.
Она проверяет миграции на SQLite в памяти, CRUD, 404, маппинг и сохранение скрытого поля, а также поиск города. Веб-сервер при проверке не запускается; демонстрация Swagger выполняется отдельно.
